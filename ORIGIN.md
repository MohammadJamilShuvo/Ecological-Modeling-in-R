# Origin and scope

This repository is a **generalized modeling portfolio**, not the analysis archive for a specific manuscript.

It was developed from statistical approaches used in the author's forest arthropod eDNA research, including:

- environmental correlation analysis;
- Poisson and negative-binomial generalized linear models;
- generalized additive models;
- random forests;
- structural equation modeling;
- richness visualization.

The original manuscript-specific repository remains available separately:

https://github.com/MohammadJamilShuvo/Shuvo_Arthropod_eDNA_ForestStructure_2025

To keep this repository reusable and easy to evaluate, manuscript-specific variable names, local file paths, and original study data were replaced by clear generic examples and synthetic datasets.
